# AI时代Python爬虫：配套源代码

本仓库是《AI时代Python爬虫：从入门到智能采集全栈实战》的配套示例。
各章代码从书稿围栏中原样抽出，按章节和小节分目录存放，便于对照书中讲解练习。

仓库地址：<https://github.com/numk/spider-book-code>

## 环境

- Python 3.12
- 依赖管理使用 [uv](https://docs.astral.sh/uv/)。也可按书中第 2 章的方式安装。
- 数据库、Redis、Docker、浏览器和抓包工具需要按对应章节另行准备，不包含在本仓库里。

第三方库清单见 `requirements.txt`。它只统计书中 Python 示例里出现过的导入，不保证每一条示例都能在缺少外部服务时直接跑通。

## 合规

示例仅用于技术学习和合法的数据采集研究。使用前请阅读本书第 14 章，遵守法律法规和目标网站的使用条款，不要把这些代码用于侵犯他人权益或突破访问控制。
